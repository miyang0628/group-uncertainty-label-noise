# Group-Level Uncertainty under Real Label Noise

Code and analysis for the paper **"When Does Group-Level Uncertainty Help Localize
Label Noise? A Methodological Study for Data-Centric and Trustworthy Learning."**

We study whether lifting uncertainty from individual examples to **groups** (taxonomy
subtrees, registered classes) helps localize **real, semantically plausible** label noise.
We introduce **GUARD** (Group Uncertainty And Residual Decomposition), a two-axis measure
separating a label-free homogeneity axis from a label-aware contamination axis, and evaluate
it on AlleNoise (K=5691) plus the real-human-noise benchmarks CIFAR-10N (K=10) and
CIFAR-100N (K=100).

## Key findings

1. **Individual confidence collapses** under semantic noise (AUROC ≈ 0.53) and *degrades* as
   the classifier trains better.
2. The group claim–belief divergence **saturates** in a large label space; a taxonomy-aware
   **subtree projection** repairs it.
3. A **cross-dataset regime law**: the label-space size *K* governs whether any group signal
   is detectable (best group-ranking AUROC ≈ 0.62 → 0.94 → 1.0 at K = 5691, 100, 10), yet at
   every *K* the GUARD decomposition **matches but never beats** a trivial per-example
   aggregation — on the single-class CIFAR benchmarks it is provably rank-identical to the
   mean per-example mismatch.

## How to reproduce

### AlleNoise track
1. `00_download_data` → `01_finetune_and_predict` (GPU). This writes
   `data/item_meta.parquet`, `data/pi_memmap.npy`, `data/label_classes.npy`.
2. Run `02`–`10` in order. They read only the nb01 artifacts (no retraining) and write all
   tables/figures under `results/`.

### CIFAR track (independent-dataset regime law)
1. `11_cifar_finetune_predict` (GPU). Set `DATASET="cifar10n"`, run; then set
   `DATASET="cifar100n"`, run again. Each writes artifacts under
   `data/cifar/<dataset>/` in the **same schema** as the AlleNoise track. The CIFAR-N human
   label files are downloaded automatically (UCSC-REAL release); if the download is blocked,
   drop `CIFAR-10_human.pt` / `CIFAR-100_human.pt` into `data/cifar/` and re-run.
2. `12_cifar_group_conditions` (CPU, fast). Reads the saved artifacts, writes
   `results/tables/t12_*.csv` and `results/figures/f12_cifar_conditions.{png,pdf}` (Fig. 8).

The CIFAR training uses a ResNet with CIFAR-standard stem, k-fold cross-fitting, mixed
precision, and GPU-resident batching (no CPU dataloader bottleneck).

## Data

- **AlleNoise** — large-scale e-commerce title classification with real misregistration and
  paired clean labels.
- **CIFAR-10N / CIFAR-100N** — CIFAR-10/100 with real human annotation noise (Wei et al.,
  ICLR 2022), paired with the original clean labels.

All datasets are public; `data/` is regenerated by the notebooks and is not tracked.
